## Project Description
The University Academic Management System is a database management system designed to efficiently manage the academic activities and records of a university. It provides a centralized platform for storing and organizing information related to students, faculty, departments, courses, enrollment, attendance, examinations, and results. The system establishes relationships between different academic records using a relational database, making data easier to access, update, and manage. It also helps reduce manual work, data redundancy, and errors while improving the accuracy and efficiency of academic record management.
